# Shapeshifter 2e Template

This module adds a new werewolf template choice to the existing `Chronicles of Darkness 2e` character sheet.

## What it does

- Adds a `Shapeshifter` entry to the werewolf template dropdown.
- Uses the system’s normal character sheet.
- Leaves the base sheet layout and item lists alone.

## Next steps

- If you want the option to be something other than werewolf-based, we can point it at a different character type.
