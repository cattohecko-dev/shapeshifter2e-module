# Shapeshifter 2e Template

This module adds a new werewolf-style template choice to the existing `Chronicles of Darkness 2e` character sheet.

## What it does

- Adds a `Shapeshifter` entry to the werewolf template dropdown.
- Replaces Harmony with a Passion box track on the sheet.
- Lets those boxes optionally add to trait and skill rolls.
- Renames the Gifts tab into the Myth tab.
- Reworks renown into 5-box tracks for Competence, Guardianship, Civility, Integrity, Empathy, and Magnanimity.
- Rebrands Gift Facets as Myth Facets with Nightmare Myths, Wyrd Myths, and Excalibur Myths.
- Uses `x` marks in the boxes instead of slash or star symbols.
